# Abhinav Idly Flyer

A standalone-ready, South Indian tiffin-themed tap-to-fly browser game. Abhinav rides on an idly and flies between golden dosa pillars. There are no Engineering Mathematics topics in gameplay.

## Run the full project
1. Extract the ZIP.
2. Open `Abhinav_Tiffin_Game/index.html` in a modern browser.

## Run the standalone version
Open `Abhinav_Idly_Flyer_Standalone.html`. It embeds the CSS, JavaScript, character image, and audio files so it can run as a single HTML file.

## Controls
- Tap/click or press Space/Arrow Up to fly.
- Use the pause and sound buttons on the game screen.
- Restart from the game-over screen.

## Theme and assets
- Player: `assets/friend.png` (Abhinav's face on the idly character).
- Obstacles: golden dosa pillars drawn directly in Canvas. They do not depend on maths images or external obstacle files.
- Optional audio: `assets/gameplay.mp3` and `assets/gameover.mp3`.
- Food labels include Masala Dosa, Plain Dosa, Medu Vada, Coconut Chutney, and Sambar.

To replace the character image, use a PNG named `friend.png` in the `assets` folder. The standalone HTML has its own embedded copy, so regenerate the standalone file after replacing assets.
