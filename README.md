# Abhinav Idly Flyer — South Indian Tiffin Edition

A local browser game: Abhinav rides a flying idli between dosa pillars.

## Run
Open `index.html` in Chrome or another modern browser. For a single-file version, open `Abhinav_Idly_Flyer_Standalone.html`.

## Tiffin names used in gameplay
- Ghee Karam Idli — నెయ్యి కారం ఇడ్లీ
- Rasam Idli — రసం ఇడ్లీ
- Palyam Dosa — పల్యం దోస
- Upma Dosa — ఉప్మా దోస
- Onion Dosa — ఉల్లిపాయ దోస
- Plain Palyam Dosa — ప్లెయిన్ పల్యం దోస
- Plain Upma Dosa — ప్లెయిన్ ఉప్మా దోస
- Plain Onion Dosa — ప్లెయిన్ ఉల్లిపాయ దోస

## Assets
- `assets/friend.png`: character face used on the idli rider
- `assets/obstacle-1.png`: vertical rolled dosa pillar sprite used by gameplay
- `assets/obstacle-2.png`: alternate uploaded dosa image (available for future variations)
- `assets/gameplay.mp3`: gameplay audio
- `assets/gameover.mp3`: game-over sound

The game falls back to drawn dosa pillars if the obstacle image cannot load. The standalone HTML embeds the current assets and scripts. No Engineering Mathematics labels are used.
